One emoji for the trip of a lifetime: 🏝️ — a desert island. No words, no
itinerary, just the postcard: palm, sand, and nowhere else to be. It is a
single code point (U+1F3DD, 4 bytes), readable at a glance on any screen, in
any culture.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

`main.ts` reads `entry.txt` (resolved via `import.meta.url`, never a relative
path), validates it is exactly one emoji of 1–8 characters with no words,
whitespace, or invisible characters, and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
